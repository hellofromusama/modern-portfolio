**1c. `ShootingStars.tsx` (new, "use client"):** Pooled comet streaks — a fixed pool of slot objects created ONCE in useMemo/useRef; respawn = reposition + restart, ZERO allocation per spawn, NO setInterval/setTimeout (all scheduling via `state.clock.elapsedTime` inside useFrame so it pauses with the frameloop).

- Pool size: `const slots = isCoarse ? 1 : 2` where `isCoarse` is computed ONCE in useMemo from `window.matchMedia("(pointer: coarse)").matches || window.innerWidth < 768` (client-only component, dynamic ssr:false upstream — safe).
- Per slot render: a `<group>` containing (1) head: `<sprite>` with the soft texture, scale ~1.6, additive, depthWrite false, white-blue tint `#cfe4ff`; (2) tail: a `THREE.Line`/`lineSegments` of 2 points from origin to `(-dirLocal * tailLen)` with `vertexColors` — head vertex near-white, tail vertex black — plus `AdditiveBlending`: additive black contributes nothing, giving a free fade-out gradient without per-vertex alpha. Tail length ~10-16 world units. `frustumCulled={false}` on both.
- Per-slot state in refs: `{ active, startTime, life, origin: Vector3, dir: Vector3, nextSpawn }`, staggered initial `nextSpawn` (e.g. 2s and 7s).
- useFrame logic: if `reduced` -> set both groups invisible, return. If `time >= slot.nextSpawn && !active`: activate — `life = 1.5 + rand`, spawn CAMERA-RELATIVE (fog eats absolute deep z): `origin.z = state.camera.position.z - 110 - rand*50` (well behind every planet local to the view), `origin.x/y = ±(30..70)` off to one side; `dir` = normalized random diagonal mostly in x/y (e.g. crossing sign of origin.x) with slight z drift; total travel distance ~90-140 units over `life`. While active: `p = (time - startTime) / life`; `group.position = origin + dir * dist * p`; orient the tail line along `dir` (set once at spawn via `group.lookAt`/quaternion — not per frame); materials' opacity = `Math.sin(Math.PI * p)` (fade in/out). At `p >= 1`: deactivate, `nextSpawn = time + 4 + rand*5`. All per-frame work is a couple of vector ops per slot — no loops over stars.
